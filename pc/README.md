# WhatsApp Web PC (Windows Desktop Edition)

Standalone Windows Desktop application for WhatsApp Web.

## How to Run on PC

### Quick Run
Double-click `run-pc.bat` or run:
```bash
npm start
```
This opens the WhatsApp Web desktop application window.

### How to Package .exe
Double-click `build-exe.bat` or run:
```bash
npm run build:exe
```
This will compile the standalone Windows executable to:
`pc/dist/WhatsApp Web-win32-x64/WhatsApp Web.exe`
